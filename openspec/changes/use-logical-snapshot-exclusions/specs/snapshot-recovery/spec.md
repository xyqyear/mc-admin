## MODIFIED Requirements

### Requirement: 忽略规则保护每一种快照和恢复写入

系统必须（SHALL）在手动和定时创建、预览、安全快照、恢复、回滚及业务数据清理中一致应用保护规则。当前配置必须（SHALL）按展开后的逻辑路径及其子树匹配，不自动将符号链接目标或其它别名加入排除集合。恢复必须（SHALL）合并当前忽略设置、源快照排除记录及恢复链保留的必要保护信息。真实路径仍必须（SHALL）用于目录边界、冲突和执行前路径变化检查。应用拥有的派生地图瓦片必须（SHALL）按缓存维护规则删除与重新生成，不受快照排除设置阻止；此例外不得（SHALL NOT）扩展为删除其他被忽略内容。

#### Scenario: 选择被忽略路径
- **WHEN** 目标逻辑路径本身处于忽略范围
- **THEN** 界面禁用相关操作并解释原因，直接提交请求也被拒绝

#### Scenario: 选择包含忽略子目录的父目录
- **WHEN** 目标同时含允许处理和被忽略的内容
- **THEN** 只处理允许内容，忽略的逻辑路径保持不变

#### Scenario: 忽略链接名称
- **WHEN** 链接 B 指向 A，用户只配置忽略 B
- **THEN** B 及通过 B 选择的子路径被忽略，直接选择 A 不因该配置被禁止

#### Scenario: 忽略目标名称
- **WHEN** 链接 B 指向 A，用户只配置忽略 A
- **THEN** 选择 A 被禁止，选择 B 不因其真实目标为 A 而被自动禁止

#### Scenario: 历史排除设置与当前不同
- **WHEN** 源快照曾排除的目录不再列于当前忽略设置
- **THEN** 恢复仍保留源快照记录的排除证据，不把其缺失当作删除指令

#### Scenario: 区块附属文件被忽略
- **WHEN** 选中区块涉及的实体、兴趣点或溢出文件逻辑路径处于忽略范围
- **THEN** 合并、移除和后续清理一致跳过相应内容，MCC 与对应区块入口共同保留

#### Scenario: 链接越界或在观察后改指向
- **WHEN** 操作目标的真实路径逃出服务器目录，或已接受范围的链接发生变化
- **THEN** 操作在写入前明确拒绝，不因逻辑忽略语义放宽目录边界

## ADDED Requirements

### Requirement: 文件界面共享服务器忽略规则

系统必须（SHALL）通过经过认证的只读请求返回服务器当前已展开的逻辑排除路径及其规则版本和服务器代次。文件列表、目录和多选按钮必须（SHALL）共享该服务器的读取结果，本地选择变化不得（SHALL NOT）逐按钮发送范围检查请求。规则未知或读取失败时必须（SHALL）保持操作禁用并提供原因；实际提交仍由后端重新校验。相关配置、世界名称和服务器数据变化后必须（SHALL）更新反馈。

#### Scenario: 打开文件页与改变选择
- **WHEN** 用户打开包含多行文件的页面，随后多选、清空、排序或翻页
- **THEN** 各按钮共用一次服务器规则读取，选择判断不产生每行范围 POST

#### Scenario: 配置更新或恢复改变规则输入
- **WHEN** 忽略配置、服务器世界名称或服务器实例数据变化
- **THEN** 当前使用规则的界面重新读取受影响服务器的规则并更新按钮提示

#### Scenario: 未认证或规则读取失败
- **WHEN** 未认证请求规则，或已认证界面的规则读取失败
- **THEN** 未认证读取被拒绝，界面不以缺失规则推断操作允许

#### Scenario: 后端范围检查仅接受世界选择
- **WHEN** 客户端向范围检查提交文件、项目或全局范围，或创建请求的备注字段
- **THEN** 请求被拒绝，不保留被共享规则读取替代的检查能力
