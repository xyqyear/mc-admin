## Why

快照忽略配置按符号链接真实目标传播，与用户配置的路径名称不一致；文件页还为每个按钮重复获取同一服务器的规则。让排除项按逻辑路径生效，并共享一次服务器规则读取，减少请求且保持展示与执行一致。

## What Changes

- **BREAKING** 当前忽略配置只匹配展开后的逻辑路径及其子树，不自动排除符号链接指向的其它路径；未被排除的别名可以操作同一份数据。
- 保留真实路径的目录边界检查、资源声明、维护归属和执行前重验；显式选择内部链接仍操作其目标。
- 备份、来源筛选、预览、恢复、回滚和缺失清理保持统一的逻辑匹配，快照与恢复链保留记录时的保护证据；不增加旧符号链接记录兼容。
- 提供服务器当前规则 GET；文件行、目录和批量选择共享缓存，在相关配置及文件变化时刷新，不逐按钮发送 POST。
- 世界选择保留布局及 MCA/MCC 关联检查；范围 POST 仅支持世界选择，删除被 GET 替代的文件、项目和全局检查能力及其测试。恢复候选和来源校验保持独立。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `snapshot-recovery`: 逻辑路径排除语义、恢复链保护证据、服务器共享规则反馈。

## Impact

涉及 backend 快照路径、保护、规划及世界适配，新增只读 API并收缩世界检查契约；frontend backups 查询与文件按钮、配置和 operation 失效注册；API E2E 和浏览器行为验证。快照及恢复证据记录逻辑范围与执行映射；线上无符号链接数据不需要路径转换兼容。无 Docker 运行模式、下载命名、玩家功能或 operations 轮询策略变更。
