## ADDED Requirements

### Requirement: 管理输入明确保留零值和目录选择

系统必须（SHALL）按用户输入更新 Cron 字段，包括有效零值与明确清空的原始字段；批量上传的目录勾选必须（SHALL）一次应用到该目录下全部文件，保留目录外选择，并按完整相对路径提交每文件覆盖决策。

#### Scenario: Cron 从非零值改为零
- **WHEN** 用户将支持零值的 Cron 字段、范围端点或间隔起点从非零值改为零
- **THEN** 表单表达式和后续保存请求保留零值语义，不回退到旧草稿；间隔起点为零时保留受支持的等价规范表达

#### Scenario: 清空原始 Cron 字段
- **WHEN** 用户明确清空原始字段
- **THEN** 受控输入保留空值，现有校验负责阻止无效提交，不恢复旧值

#### Scenario: 目录覆盖选择
- **WHEN** 用户勾选或取消嵌套上传目录
- **THEN** 全部子文件的覆盖决策一致更新，目录外决策保留，半选状态反映真实选择
- **AND** 不同目录下同名文件按各自相对路径和内容上传

### Requirement: 失败输出排除敏感适配器数据

系统必须（SHALL）从新的 HTTP、WebSocket、请求流、任务执行历史和普通日志错误输出中排除原始凭据、请求参数、适配器异常值和通知 URL。明确撰写的安全消息和受支持结构化字段必须（SHALL）保留；错误分类、状态码、取消、连接关闭和已保存历史的保留策略必须（SHALL）保持。

#### Scenario: 适配器异常包含敏感值
- **WHEN** 上传、控制台、玩家资料、Cron 参数或备份通知的适配器失败包含敏感值
- **THEN** 新公开错误、执行历史和应用日志不包含该值，仍提供安全提示及错误类型诊断
- **AND** 现有部分结果、业务状态和后续可用操作保持

#### Scenario: 明确安全的业务拒绝
- **WHEN** 系统产生明确撰写的权限、冲突或输入约束错误
- **THEN** 受支持状态和安全结构化字段继续可读，不因日志净化改变分类
