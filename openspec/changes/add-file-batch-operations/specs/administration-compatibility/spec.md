## ADDED Requirements

### Requirement: 服务器概览原地查看玩家详情
系统 SHALL 在点击服务器概览中的在线玩家卡片时打开现有玩家详情弹窗，支持键盘操作，且不导航离开当前页面。在线列表刷新、玩家离线或服务器状态变化 SHALL NOT 关闭已打开详情。关闭弹窗 SHALL 保留概览页面位置。

#### Scenario: 原地查看并关闭
- **WHEN** 管理员在服务器概览点击一个在线玩家并关闭详情
- **THEN** 弹窗展示该 UUID 对应的已有玩家资料与记录，页面地址和所在概览保持不变

#### Scenario: 在线列表变化保留详情
- **WHEN** 查看详情期间玩家从在线列表消失
- **THEN** 详情继续展示所选玩家，直到用户关闭或明确切换玩家
