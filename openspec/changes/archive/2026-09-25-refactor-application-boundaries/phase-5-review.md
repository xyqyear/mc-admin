## 用户可观察的修正

- 服务器删除并重建同名实例后，旧恢复记录仍可查看，但不会把旧安全快照自动恢复到新实例；归属不明确的历史记录同样拒绝自动回滚。
- 恢复删除最后一个区域或原范围已经不存在后，回滚仍按记录的范围工作。回滚本身保存安全快照和原先缺失的目录信息，可以再次反向回滚。
- 安全快照完成事件发出前，恢复历史与引用已经落库；即使在这一刻断开连接，仍能找到可恢复的中断记录。
- 已确认存在的空快照目录，以及父目录存在但所有选中文件在快照中缺失的恢复范围，会真正清理所选的现有内容，且保护忽略路径、未选文件和 dry-run 语义。快照中不存在父目录的普通恢复仍沿用既有规划契约。
- 裁剪页面能区分预览过期、数据变化和已被消费；第二次点击不会启动另一个删除任务。应用任务记录实际操作者，预览仍保留创建者。
- 在应用裁剪时关闭任务记录，不会删除仍在使用的领地保护文件或预览几何数据；后端重启后旧任务历史不会重新授予预览应用权限。
- 新建预览与后台清理并发时，清理以最新引用状态为准；关闭预览也不会在 PNG 响应读取完成前删掉对应文件。
- 地图实际渲染、初始化、文件直接编辑及恢复的缓存清理共享对应资源范围。清理失败会标记缓存降级；指向服务器外部的缓存符号链接不能触发越界删除。
- 失败的预览流在操作日志中保留失败结果，地图初始化错误不会直接暴露适配器异常或 stderr。后台任务与请求所属操作的终态均在必要收尾后发布。

## 结构与兼容性

恢复历史迁移 `2026092503` 只增加 `server_generation` 和 `binding_issue`，按保留的实例生存期谨慎回填，不改原历史 ID、状态、快照引用或选择 JSON。含恢复历史的数据库禁止降级删除这些身份字段。迁移与回滚演练只使用隔离测试数据库。

新的恢复记录保存经过约束的 `world_roots` 和 `absent_directories`；旧 `absent_sidecar_dirs` 元数据继续读取。需要为空范围生成安全快照时，仅在已声明范围内创建唯一空占位目录，备份后执行有限清理，不把未选区域一并纳入备份。历史路径重用前仍校验实例、目录约束和实际资源范围。

产物目录采用 `/tmp/mc-admin-world-artifacts/<installation>/<feature>/<token>`。安装命名空间由数据库和服务器根路径生成；功能目录区分恢复预览、裁剪预览和恢复暂存。启动先处理操作日志，再清理确定无主的产物。显式保留的恢复引用不会因普通任务状态已结束而丢失。

API 契约以原始基线加经过审查的增量断言验证，没有重录基线来掩盖差异。恢复响应只增加可选的身份字段；裁剪状态保留旧任务字段并提供预览有效性状态。前端既有进度、错误提示和任务状态继续兼容。

## 验证与运行边界

- 本组 UI 证据来自真实 QueryClient 与 MSW 集成测试；完整浏览器 Playwright 流程属于第 7 组，不能将这些测试表述为浏览器端到端验收。
- 继续要求单数据库及服务器根目录只有一个后端写入进程。租约约束应用内操作，不能隔离任意外部程序的直接文件修改。
- mcmap apply 会重新扫描；输入版本检测受理和执行前的变化，不承诺底层尚不支持的冻结区块选择清单。
- 缓存更新失败与世界写入是否完成分开记录；不会自动重放破坏性操作，也不会把取消或恢复确认改写为成功。
- 本阶段未提交 Git、发布镜像、部署或迁移实际用户数据库。IDE diagnostics 工具不可调用，静态检查使用项目的 Pyright、Ruff、TypeScript 和 ESLint。
