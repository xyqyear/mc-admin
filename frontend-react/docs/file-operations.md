# 文件选择、批量操作与本地下载

文件列表和高级搜索共用 `FileBatchActions`。用户明确选中的文件与真实目录构成一个范围，可创建快照、选择恢复来源、打包、删除或直接下载到本地文件夹。选中真实目录包含全部子树；父子路径同时选中时，后端和直接下载执行器去除重复范围。搜索树中展示路径的分组目录可勾选，聚合该组下实际搜索命中项，支持全选、部分选择和清空；清空分组保留组外选择。分组目录自身不进入操作范围，未命中的相邻文件保持不变。

列表选择由服务器、当前目录、已执行搜索词和正则模式共同标识。翻页、排序和编辑尚未执行的搜索词保留选择；目录、服务器或执行筛选变化清空选择，包括浏览器前进、后退。高级搜索每次请求清空选择，结果绑定响应的 `search_path`。修改输入草稿不改变已有结果的范围；重置或关闭后的迟到响应不能恢复旧结果。

所有操作捕获提交时的路径数组。后台删除受理一个任务，终态逐项结果区分已删除、失败和未执行；只有成功删除的路径及后代从选择中移除。失败项保留供用户查看和重试。任务终态的文件缓存刷新由应用级操作观察器承担。压缩受理后，在首个任务详情返回前仍阻止重复提交；生成独立归档后显示下载入口。

快照操作沿用公共多路径 scope 与恢复历史。当前规则过滤被忽略的选中根路径，混合选择继续处理其余内容；全部被忽略时禁用。恢复来源通过 `/snapshots/eligible` 合并当前与来源保护，每个允许根都必须被覆盖或有原先不存在的证据，缺少覆盖不等于忽略。来源返回 `skipped_paths` 与 `skipped_count`，选择表和预览共用 `SnapshotSkipNotice` 展示权威跳过信息，不在前端解释仓库标签或绝对排除路径。原始选择完整提交，后端决定实际范围；回滚保留上次跳过保护。创建、编辑和选择来源时共用备注，最多 500 个 Unicode 字符。备注保存失败时显示已创建快照 ID，重试仅写入备注。

`FileSnapshotRecovery` 在进入文件页时读取一次服务器详情身份和 `GET /snapshots/targets/rules`。规则返回服务器代次、版本及已展开 `<LEVEL_NAME>` 的数据目录相对逻辑路径；文件行、根目录、多选和高级搜索共享同一缓存，本地选择、排序和翻页不发送范围 POST。路径按完整路径段和子树匹配，父子范围合并去重；配置忽略链接名称只影响该名称，不自动禁止真实目标或其它别名。规则正在读取、读取失败或代次与服务器详情不匹配时保留禁用。

规则缓存无周期轮询。重新进入、网络重连、显式刷新及输入变化按需读取；保存或重置快照配置刷新全部服务器规则，文件写入、上传、恢复、填充和服务器身份变化刷新相关服务器。规则使用独立查询前缀，普通快照创建及归档校验不使它失效。`POST /snapshots/targets/check` 只接收世界范围的 `scope`，用于布局发现、维度及 MCA/MCC 关联检查，不接收备注。文件范围使用规则 GET 与本地判断，来源快照筛选独立；实际提交和写入前保留后端权威校验。

文件列表的已选数量与批量操作按钮位于表格和分页下方，高级搜索的对应操作位于结果树下方。没有选择时操作区域不参与布局或交互，不保留空白行；选择或清空只改变列表下方的内容，不移动文件行。高级搜索弹窗固定顶部位置并限制滚动高度，预留滚动条空间，底部操作区域出现时不重新居中或挤压结果。批量操作组件保持挂载，保留进行中的任务和弹窗状态。忽略规则正在检查、禁止操作或跳过部分内容的说明使用快照按钮的悬浮提示，不插入额外文字行，异步检查完成不改变文件列表位置。

文件页、世界恢复页与历史弹窗共享活动恢复发现。每个 QueryClient 和服务器范围只有一个轮询计时器，成功的空结果每 30 秒刷新，活动、未知和失败状态每 2 秒检查。进入或重新启用界面读取最新状态，检查完成前和读取失败时保留恢复提交保护。历史列表在打开、显式操作和查询失效时刷新，不为进度重复核对 Restic 仓库。

## 浏览器目录导出

`useDirectoryDownload` 检查安全上下文、`showDirectoryPicker` 和 `FileSystemFileHandle.createWritable`。支持的浏览器通过用户点击同步发起目录选择；授权后在所选位置建立独立子目录。导出目录和压缩包均使用文件系统安全的服务器名与浏览器本地时间 `YYYYMMDD_HHmmss_SSS`，例如 `dev_20261007_154200_123`；压缩包添加 `.7z` 扩展名。名称不含路径片段或随机标识，存在同名时增加 ` (2)` 等序号并保留已有内容。压缩命令通过 `client_timestamp` 传递本地时间，不使用 UTC ISO 字符串或后端时区。按钮在不支持的浏览器中保留并禁用，悬浮显示“当前浏览器不支持直接下载到文件夹，仅支持 Chrome 和 Edge。”；能力受 HTTP 环境限制时提示使用 HTTPS 或 localhost。打包功能独立可用。

原路径布局以列表当前目录或捕获的搜索根为基准，保留相对目录和空目录。平铺只保留文件；同名文件、大小写冲突、Windows 保留名、非法字符和过长文件名映射为安全名称，任务中心展示映射提示。导出目录独立于已有内容，不覆盖已有文件。

执行器分页读取递归清单，每页最多 200 个条目，最多四个文件同时请求并写入。清单和文件 GET 都绑定同一服务器代次；改变代次或目录结构使任务明确失败。清单可能反映源文件的不同时间点，下载不是快照。响应流直接写入浏览器文件句柄，关闭写入流后才增加完成文件数量。单文件失败不阻断其他文件；整批枚举失败与逐文件失败分别呈现。

浏览器接口没有统一的总文件数量上限，应用不按文件总数截断导出。实际能力取决于磁盘空间、路径长度、系统文件数量及小文件请求耗时。元数据和路径映射随条目数增长；每次仅保留有限并发的文件流，不把整个导出读入内存。

任务中心记录累计字节、已发现和完成的文件数、失败原因以及本地目标位置。关闭任务面板或在应用内换页不停止下载。取消中止请求和写入，移除未完成的新文件并保留已经完成的文件。刷新或关闭页面无法恢复文件句柄，持久化记录标记为取消。
